# מאגר מבחנים ומטלות — אלגברה לינארית 1 (20109)

יובא מהארכיון שסיפק המשתמש ב־6 בנובמבר 2026. המקור נשאר ללא שינוי.

- 32 מבחנים ו־15 מטלות; 389 שאלות וסעיפים.
- ל־356 שאלות וסעיפים צורפו תמונות פתרון, מתוכן 18 עם מפתח תשובות בלבד.
- 33 שאלות בחמש מטלות 2027א (01, 02, 04, 06, 07) ללא פתרון בארכיון.
- 1,056 הפניות לתמונות נשמרו; 965 תמונות ייחודיות לאחר איחוד לפי SHA-256, ללא שינוי בתוכן התמונה.
- כל 89 הקבצים בעלי סיומת PDF הם למעשה אותו דף HTML. הם אינם מצורפים כקובצי PDF תקינים.
- בשמות קובצי הפתרונות של מטלות 06 ו־07 בסמסטר 2026ג מופיע 2026ב. השיוך נשמר כפי שסופק ומסומן באתר; התאמה מתמטית של הפתרונות לא נבדקה.
- תוקנו זוגות surrogate בקידוד CESU-8 בתוך טקסט UTF-8. התמלול לא נערך מתמטית; תמונות המקור מוצגות כגרסה הקובעת.
- תמונות עמודים מהספר שבתיקיית `assets/references` אינן חלק מייבוא המבחנים והמטלות. ההפניות למקור, הסיווגים וטקסטי השאלות והפתרונות נשמרו בנתוני המאגר.

המאגר נטען רק בפתיחת „מבחנים ומטלות” בקורס לינארית. ניתן לסנן לפי סוג, שנה, פרק או טקסט ולפתוח כל פתרון בנפרד. הבנייה מעתיקה את הנתונים והתמונות ל־`docs/linear1/assets/archive/`.

`import-report.json` מכיל רשימת קבצים מקוריים, טביעות SHA-256 ורשימת החוסרים. אין בו טענה לבדיקה עצמאית של נכונות הפתרונות או של תיוגי הנושאים.

ייבוא חוזר:

```sh
python3 tools/import-linear1-archive.py /path/to/openu-20109-full-archive
npm run build
npm test
```

כל הזכויות בחומרי המקור שמורות לבעליהן.
