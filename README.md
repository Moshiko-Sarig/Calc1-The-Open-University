אתר סטטי מלא לקורס חשבון אינפיסימטלי 1.

> חשוב: עמוד ה-repository ב-GitHub מציג את README בלבד.  
> ה-UI המלא נמצא באתר GitHub Pages או בקבצי האתר תחת `docs/`.

## כניסה לאתר

אחרי הפעלת GitHub Pages:

[https://moshiko-sarig.github.io/Calc1-The-Open-University/](https://moshiko-sarig.github.io/Calc1-The-Open-University/)

אם הקישור מציג `404`, צריך להפעיל Pages:

1. Repository Settings
2. Pages
3. Build and deployment
4. Source: `Deploy from a branch`
5. Branch: `main`
6. Folder: `/docs`
7. Save

אפשר גם להשתמש ב-GitHub Actions, אבל `/docs` הכי פשוט כי כל האתר כבר בנוי ומחויב לריפו.

## מה יש באתר

- **ניווט לפי הקורס**: עץ יחידות בצד ימין (במסך צר הוא נפתח ככפתור תפריט), עם סדר הלימוד של כל יחידה לפי "ציר לימוד" בשער שלה. ★ מסמן פתק שיש בו משפט מהרשימה לבחינה.
- **דף פתק**: פירורי לחם, זמן קריאה, "בדף הזה" (תוכן עניינים שמסמן את הסעיף הנוכחי), קישור ישיר לכל סעיף, פתק קודם ופתק הבא, ופתקים שמפנים לכאן.
- **חיפוש**: לפי שם, כינוי או תוכן, כולל מספרי משפטים. `/` או `Ctrl+K` פותחים אותו, חצים בוחרים ו-Enter פותח.
- **קריאה נוחה**: מצב כהה, שלושה גדלי טקסט (נשמרים בדפדפן), והמשך קריאה מהדף האחרון בדף הבית.
- **נגישות**: מבנה כותרות תקין, כותרת דפדפן לכל דף, ניווט מלא במקלדת, ניגודיות AA בשני המצבים, ויעדי מגע של 44px במסכים צרים.

## עברית ומתמטיקה באותה שורה

- הטקסט באתר הוא RTL. כל נוסחה (`$...$` או `$$...$$`) נבנית כ"אי" LTR מבודד (`dir="ltr"`, `unicode-bidi: isolate`), כך שסימנים, סוגריים ותחיליות כמו "ב-" ו"ו-" לא מתהפכים.
- הנוסחאות מסומנות לפני עיבוד ה-Markdown, ולכן `*`, `_`, `[` ו-`|` בתוך TeX לא נשברים.
- עברית בתוך `\text{...}` מוצגת כרצף אחד (MathJax `mtextInheritFont`), ולכן אינה הפוכה.
- נוסחה שרחבה מהעמודה במסך צר הופכת לשורה נגללת משלה, וטבלאות ונוסחאות תצוגה נגללות בתוך המסגרת.
- תרשימי Mermaid זורמים מימין לשמאל, והתוויות בעברית מוצגות RTL.

## תוכן ומקורות

- שמות היחידות באתר הם השמות שבכרכי הקורס, ומספרי ההגדרות והמשפטים בפתקים אומתו מול חוברת ההגדרות והמשפטים.
- [רשימת המשפטים לבחינה](חשבון%20אינפיסימטלי%201/00%20-%20מרכז%20הכספת/רשימת%20המשפטים%20לבחינה%20-%20אינפי%201.md): 35 המשפטים מהרשימה הרשמית, עם קישור להוכחה המלאה של כל אחד.


```text
http://127.0.0.1:4173/
```

## ייחוס

האתר הוא אתר לימודי לא רשמי. הפתקים מבוססים על חומרי הקורס 20474 של האוניברסיטה הפתוחה ועל סיכום הרצאות אינפי 1מ של אביב צנזור מהטכניון. כל הזכויות בחומרי המקור שמורות לבעליהן.

אין להעלות ציבורית ספרים, חוברות, PDFs רשמיים, הקלטות או פתרונות רשמיים ללא הרשאה מפורשת.
