# כללי הגזירה

> מקור: כרך ג, פרק 7.3 (משפטים 7.13–7.20)

## הכללים

בהנחה ש-$f,g$ גזירות ב-$x_0$:

| כלל | נוסחה | מקור |
|---|---|---|
| סכום/הפרש | $(f\pm g)' = f' \pm g'$ | 7.13 |
| קבוע | $(cf)' = c f'$ | 7.15 |
| **מכפלה (לייבניץ)** | $(fg)' = f'g + fg'$ | 7.14 |
| חזקה של פונקציה | $(f^n)' = nf^{n-1}f'$ | 7.17 |
| הופכי | $\left(\frac1g\right)' = -\dfrac{g'}{g^2}$ (כש-$g(x_0)\ne0$) | 7.19 |
| **מנה** | $\left(\frac fg\right)' = \dfrac{f'g - fg'}{g^2}$ | 7.18 |
| חזקה שלמה | $(x^n)' = nx^{n-1}$, גם לשלילי | 7.16, 7.20 |

## רעיונות ההוכחה

- **מכפלה** — טריק ההוספה והחיסור (כמו ב[[אריתמטיקה של גבולות סדרות]]):
$$\frac{f(x)g(x)-f(x_0)g(x_0)}{x-x_0} = \frac{f(x)-f(x_0)}{x-x_0}g(x) + f(x_0)\frac{g(x)-g(x_0)}{x-x_0}$$
והגבול משתמש ברציפות $g$ ([[הגדרת הנגזרת|גזירה ⟹ רציפה]]).
- **מנה** — מוכיחים קודם את ההופכי ואז מכפלה: $\frac fg = f\cdot\frac1g$.
- שימו לב: הנגזרת של מכפלה **אינה** מכפלת הנגזרות!

## מסקנה: גזירת פולינומים ורציונליות

כל [[פונקציות אלמנטריות|פולינום]] גזיר בכל הישר:
$$p(x)=\sum a_k x^k \implies p'(x) = \sum k\,a_k x^{k-1}$$
וכל פונקציה רציונלית גזירה בתחום הגדרתה (כלל המנה).

## גזירה לוגריתמית

עבור $y = f(x)^{g(x)}$ (בסיס ומעריך משתנים): כותבים $y = e^{g\ln f}$ וגוזרים עם [[כלל השרשרת]]:
$$y' = f^g\left(g'\ln f + g\frac{f'}{f}\right)$$

## כרטיס דיוק

- **רעיון-על**: כללי הגזירה הם אלגברה של קירובים ליניאריים, לא רשימת טריקים מנותקת.
- **מתי מפעילים**: בגזירת סכום, מכפלה, מנה, פולינום, רציונלית ולוג גזירה.
- **בדיקה עצמית**: גזרו $x^2\ln x$ בשתי דרכים: כלל מכפלה וגזירה לוגריתמית.
- **מלכודת**: בכלל מנה חייבים מכנה לא אפס בסביבה הרלוונטית.
- **קישור רוחב**: ראו גם [[מפת תלות משפטים - אינפי 1]], [[תבניות הוכחה באינפי 1]], [[אינדקס דוגמאות נגד - אינפי 1]].
